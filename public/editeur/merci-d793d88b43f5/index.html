Installation (10 minutes, une seule fois)

  1. Crée un dossier Mes vidéos et mets-y le fichier .zip (sans le décompresser).
  2. Ouvre l'application Claude sur ton ordinateur → nouvelle conversation → Local → choisis ton dossier.
  3. Copie-colle ce message :
    Installe le fichier mon-editeur-video.zip qui est dans ce dossier : décompresse-le dans mon dossier de compétences (~/.claude/skills/mon-editeur-video), puis lance la vérification et installe ce qui manque.
  4. Accepte quand il te demande d'installer ffmpeg et les outils. À la fin : « TOUT EST PRÊT ✓ ».

Le guide complet (style, montage, révisions) est dans le fichier LISEZ-MOI.md du zip.
